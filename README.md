# numberName

A calculator-style talking number pad for little kids. Type any whole number (up to 3,003 digits) and tap **Say it!** to hear its name. Each comma group lights up as it's spoken.

**Live:** https://seanbartz.github.io/numberName/

- Short-scale American names; beyond nonillion it uses the Conway–Wechsler system (decillion, vigintillion, centillion, … novenonagintanongentillion).
- Speech uses the device's built-in voice (Web Speech API), so it works offline once loaded.
- Add to Home Screen for a full-screen app.
